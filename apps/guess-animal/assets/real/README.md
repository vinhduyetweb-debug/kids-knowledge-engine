# Real Asset Replacement

Place real production assets here.

## Thumbnails

Path:

`assets/real/thumbnails/`

Recommended:
- `.webp`
- square image
- 512x512
- under 150KB per file
- lowercase filename
- no spaces
- no Vietnamese accents in filename

## Mascot

Path:

`assets/real/mascot/owl-guide.webp`

Recommended:
- transparent background if possible
- under 300KB

## Sounds

Path:

`assets/real/sounds/`

Expected files:
- `correct.mp3`
- `wrong.mp3`

Recommended:
- under 500KB each
- short sound, 0.5-2 seconds
- friendly, not startling for children

## Copyright

Use only original, licensed, or self-created assets.
Do not use copyrighted cartoon characters without permission.
